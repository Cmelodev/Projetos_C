# 💻 Projetos em C

Este repositório reúne projetos, exercícios e desafios desenvolvidos na linguagem **C** durante minha formação em **Sistemas de Informação**. O objetivo é fortalecer os fundamentos da programação, da lógica computacional e da resolução de problemas, utilizando uma das linguagens mais importantes para o aprendizado de estruturas de dados e algoritmos.

## 🚀 Objetivos

* Praticar lógica de programação.
* Aprimorar a resolução de problemas.
* Consolidar os fundamentos da linguagem C.
* Desenvolver programas utilizando boas práticas de programação.
* Criar uma base sólida para o estudo de estruturas de dados e algoritmos.

## 📚 Conteúdos abordados

Os projetos presentes neste repositório incluem conceitos como:

* Variáveis e tipos de dados
* Operadores aritméticos, relacionais e lógicos
* Estruturas condicionais (`if`, `else`, `switch`)
* Estruturas de repetição (`for`, `while`, `do-while`)
* Funções
* Vetores e matrizes
* Strings
* Ponteiros
* Manipulação de arquivos
* Estruturas (`struct`)
* Alocação dinâmica de memória
* Algoritmos básicos

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Cmelodev/Projetos_C.git
```

2. Entre na pasta do projeto:

```bash
cd Projetos_C
```

3. Compile um dos arquivos:

```bash
gcc nome_do_arquivo.c -o programa
```

4. Execute o programa:

**Windows**

```bash
programa.exe
```

**Linux/macOS**

```bash
./programa
```
